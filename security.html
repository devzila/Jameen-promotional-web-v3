DATA PROTECTION

Protecting the information your community depends on.

Jameen handles sensitive operational information such as resident records, invoices, payments, complaints, visitors, staff activity and accounting information. Protection is built into the platform architecture.

Data in transit

Communication between users and Jameen services is protected through encrypted HTTPS connections.

  • HTTPS / TLS connections
  • Encrypted browser-to-API communication
  • Secure API endpoints
  • Encrypted authentication traffic

Data at rest

Stored application and infrastructure data is protected using encryption capabilities of the underlying cloud infrastructure.

  • Protected database infrastructure
  • Encrypted storage
  • Controlled infrastructure access
  • Backup protection

Tenant isolation

Jameen is designed as a multi-tenant platform with organisation boundaries between companies and societies.

  • Tenant-aware data access
  • Property-level boundaries
  • Role-based authorization
  • Controlled cross-property visibility

Financial data protection

Financial operations are designed around controlled transactions, auditability and immutable accounting records.

  • Invoice records
  • Payment allocations
  • Accounting journal entries
  • Credit and debit notes
ACCESS CONTROL

Everyone gets the access they need — and no more.

A resident should not have access to accounting administration. A security guard should not have access to financial reports. A property manager may need access to one property but not another.

Resident access Access personal profile, invoices, payments, maintenance requests, notices and permitted community information.
Staff access Access operational modules according to assigned role and property responsibilities.
Property manager access Manage the properties and operational information assigned to the manager.
Company administrator Manage users, properties, roles, configuration and company-level reporting.
Property-level permissions A user can be restricted to one property, multiple properties or the entire company portfolio.
Principle of least privilege Access should be granted according to the user's actual responsibility rather than giving every user administrator-level privileges.

APPLICATION SECURITY

Security across the application stack.

Jameen's security model extends beyond the login screen. Application access, APIs, databases, infrastructure and operational activity all form part of the security boundary.

Authentication Secure authentication mechanisms help verify that users are who they claim to be before accessing protected resources.
Authorization Users are authorized according to their roles, tenant, property assignments and permitted modules.
API security Protected API endpoints enforce authentication and authorization before allowing access to application resources.
Input validation Application inputs should be validated and handled safely to reduce common application security risks.
Database protection Database access is restricted to authorized application and infrastructure components.
Secret management Credentials, tokens and infrastructure secrets should never be exposed through application source code or public interfaces.
Dependency security Application dependencies should be regularly reviewed and updated to address known security vulnerabilities.
Error handling Production errors should not expose sensitive database, infrastructure or authentication information to end users.
